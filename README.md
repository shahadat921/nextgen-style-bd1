## Deploy করার নিয়ম

### ধাপ ১ — এই ফোল্ডারটা GitHub-এ আপলোড করো
1. github.com এ যাও
2. "New Repository" বানাও — নাম দাও: `nextgen-style-bd`
3. ফাইলগুলো upload করো

### ধাপ ২ — Vercel-এ Deploy করো
1. vercel.com এ যাও
2. "Add New Project" ক্লিক করো
3. GitHub থেকে `nextgen-style-bd` repo select করো
4. "Deploy" চাপো — ব্যস!
